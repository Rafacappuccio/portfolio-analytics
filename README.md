# Portfólio de Analytics & Web Development: Indicadores de Atendimento e Saúde

Este repositório centraliza o desenvolvimento do meu portfólio profissional, combinando o desenvolvimento de uma aplicação web responsiva em JavaScript com a construção de um dashboard analítico focado em inteligência de negócios.

O objetivo do projeto é simular um cenário real de otimização de fluxos operacionais, faturamento e gestão de demandas no setor de saúde, aplicando tecnologia para transformar dados brutos em decisões estratégicas.

---

## 🎯 O Desafio de Negócio (Cenário Prático)
Em grandes operações de atendimento e saúde (como gestão de faturamento, contratos e reembolsos), o alto volume de dados dispersos dificulta a identificação de gargalos. Este projeto propõe uma solução para:
* Monitorar o tempo médio de resolução de casos complexos (SLAs).
* Analisar o volume de faturamento e taxas de aprovação/negativa de reembolsos.
* Segmentar os principais indicadores de satisfação entre clientes PF e PJ.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

### Dados & Business Intelligence (BI)
* **Microsoft Excel:** Estruturação, limpeza de dados e criação da base operacional fictícia.
* **Power BI & Power Query:** Modelagem de dados, tratamento de tabelas (ETL) e criação de dashboards interativos com foco em regras de negócio.

### Desenvolvimento Web & Infraestrutura
* **HTML5 & CSS3:** Estrutura e estilização da interface do portfólio.
* **JavaScript (ES6):** Lógica da aplicação web e manipulação dinâmica de elementos.
* **Git & GitHub:** Controle de versão e organização do código.
* **Vercel:** Deploy contínuo da aplicação web conectada ao repositório.
